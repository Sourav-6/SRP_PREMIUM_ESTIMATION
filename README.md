# Health Insurance Premium Calculator

A dynamic, front-end only health insurance premium calculator built with HTML, CSS, and Vanilla JavaScript. The application allows users to configure family members, sum insured, deductibles, and plan-specific riders to calculate exact final premiums across various health insurance plans.

## Features

* Dynamic Member Configuration: Add up to 10 members with age and relationship specifications.
* Multi-Plan Support: Calculates premiums for HDFC Optima Secure, Optima Secure Plus, Optima Super Secure, and Aditya Birla plans.
* Plan-Specific Riders: Isolated toggle settings for riders (Unlimited Restore, Limitless Rider, etc).
* EMI Options Comparison: Instantly compare Annual payment default against calculated Loan EMI and Monthly Split options.
* Detailed Breakdown: Interactive pricing tables with expandable rows to view exact base premiums, member discounts, long-term discounts, and GST.
* PDF Export: Download calculated breakdowns instantly as PDF files.
* Dark Mode: Native theme toggling for enhanced readability.

## Setup

Since this is a client-side web application, no build tools or servers are required.

1. Clone the repository.
2. Open index.html in any modern web browser.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* html2canvas & jsPDF
